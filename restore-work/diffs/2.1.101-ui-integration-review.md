# 2.1.101 UI integration cross-review

## Scope and method

- Hop: official `2.1.100 -> 2.1.101`, with official `2.1.108` as the persistence baseline.
- Current tree: HEAD `9b42b77645d99e0fb2ec9ecd032857a6ef2ba194` (`restore: align TypeScript tree with official 2.1.108`).
- Raw candidate scope: every `verdict: "FAIL"` row in `verdict-shard-0..7.jsonl` whose current or suggested TypeScript location is under `src/ink/**`, `src/components/**`, `src/screens/**`, or `src/keybindings/**`.
- Report scope: all UI-related candidate behaviors in `2.1.101-ui-review.md`, plus report findings from the other three domain reviews whose implementation lands in the requested directories. The tools review contributed no additional FAIL in these directories; its `/mcp` UI row is already implemented and was not a raw FAIL candidate.
- Evidence: actual declaration neighborhoods in official 2.1.100, 2.1.101, and 2.1.108 bundles; current TypeScript bodies; `REVIEW-PROTOCOL.md`; the 2.1.101 changelog; and the HEAD commit message. Extraction evidence is retained under `2.1.101-index/_run2-integration-ui/`.
- Verdicts are integration verdicts, not copies of the source verdicts. `DUPLICATE` means the behavior is real but belongs to another canonical row/unit. `REJECTED` includes already-present behavior, non-persistent 101 behavior, vendor-only behavior, or non-behavioral equivalence.

## Result

**Confirmed canonical behavior count: 14.**

The 14 confirmed behaviors collapse to **12 ordered implementation units** because the two multi-select behaviors form one coupled unit, while the terminal-clear behavior and non-fullscreen offscreen-diff behavior form a second coupled renderer unit. The duplicate `ab1` row is already excluded from the count of 14.

The HEAD message requires one correction: it says to retain the 2.1.100 three-message thinking schedule and not pull “108's later five-message timings.” Direct bundle evidence shows that the five-message sequence was introduced in **2.1.101** at 30s/60s/90s/150s/240s; 2.1.108 retained those five messages and only retimed them to 10s/30s/50s/80s/120s. This is therefore a real 101 gap, not a later-hop-only choice.
