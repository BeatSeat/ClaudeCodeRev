### 2. `cd && git …` no permission prompt when `cd` is a no-op — LANDED

Official 113 adds `gA5` / `FA5` / `j27` / `D27` / `Z38`:

- `Z38`: `realpath`, Windows lowercased.
- `D27`: dest must be absolute or `./` / `../` (not bare `.`/`..`); reject `$`, glob, Windows `%`; dest realpath === cwd realpath.
- `gA5`: AST path — every `cd` is dest-only (no env/redirects, argv `cd <dest>`), dest parses via `j27`, `D27` vs cwd.
- `FA5`: text path for pipe segments.
- Ask reason becomes “changes directory before running git, which can execute untrusted hooks…”.
- Main path: `if (hasGit && !await gA5(…)) ask`. Pipe path: `if (!(O ? await O(D) : !1)) ask`.

`BA5` (was 111 `vkY`/`GkY`) now also accepts dest `.` / `..` and rejects `[*?[]]`.

TS: `src/tools/BashTool/bashPermissions.ts` (`parseCdDestination`, `isCdDestNoop`, `areAstCompoundCdsNoops`, `areTextCompoundCdsNoops`, `resolveLeadingSafeCd`). `src/tools/BashTool/bashCommandHelpers.ts` takes optional `areCompoundCdsNoops`.
