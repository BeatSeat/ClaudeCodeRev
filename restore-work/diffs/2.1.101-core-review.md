## FAIL list

1. **Item 2** — shared remote eligibility still rejects an empty environment list before the existing auto-create path can run.
2. **Item 3** — print/headless `--resume` still accepts only UUID/URL/JSONL, not `/rename` or `--name` titles.
3. **Item 6** — plan dialog does not include the official web reachability/org-auth eligibility guard.
4. **Item 9** — timestamp chain fallback can cross between main and sidechain messages.
5. **Item 12** — cleanup lacks the setting-source guard that prevents an unintended 30-day fallback.
6. **Item 13** — named worktree creation lacks safe stale-directory detection and recovery.
7. **Item 16** — `/context` header uses API usage while Messages/Free space retain independently estimated totals.
8. **Item 18** — internal settings writes reset read caches but suppress the watcher without refreshing live AppState.
9. **Item 21d** — `getOrganizationUUID()` does not directly honor `CLAUDE_CODE_ORGANIZATION_UUID`.
