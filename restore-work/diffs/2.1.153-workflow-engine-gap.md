# 2.1.153 Workflow engine gap

`call()` is mounted on official `uZ_.call` after `V74` + `bZ` + `DP8`:

`wf_${uuid}` → `generateTaskId("local_workflow")` → `compileWorkflowScript` (`vm.Script`) → `registerLocalWorkflowTask` (`rm6`) → return `{data:{status:"async_launched",taskId,runId,summary}}` immediately → background IIFE runs `runCompiledWorkflow` (`cK4`) → `applyWorkflowProgress` (`om6`) → `completeLocalWorkflowTask`/`failLocalWorkflowTask` (`am6`/`YP8`) → `notifyLocalWorkflowTask` (`OP8`) → `tengu_workflow_launched` / `tengu_workflow_completed`.

Interpreter is official `vm.Script.runInContext`. Agent spawn is official `runAgent`.
