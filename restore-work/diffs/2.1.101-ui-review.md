# 2.1.101 UI and terminal review

## Scope and method

- Hop reviewed: official `2.1.100 -> 2.1.101`.
- Current baseline checked against: official `2.1.108` and current `src/**/*.ts(x)`.
- Inputs used: `REVIEW-PROTOCOL.md`, the added/removed/string product indexes, genuine shards, and the actual official `2.1.100`, `2.1.101`, and `2.1.108` `cli.js` bundles. No prior review, transcript, or ledger was used.
- Verdict rule: `FAIL` is used only when (1) 2.1.101 contains the behavior, (2) current TypeScript is missing or incorrect, (3) the behavior is not protected only by a default-false GrowthBook gate, and (4) 2.1.108 still contains it.
